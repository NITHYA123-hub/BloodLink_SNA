BloodLink - Healthcare Network Analytics

About the Project

BloodLink is a student project that uses Social Network Analysis to explore the geographical distribution and connectivity of blood banks across India.

What can you explore?

  • Search and explore blood bank directory records.
  • View blood bank locations on an interactive map.
  • Find geographically nearby blood banks.
  • Explore network connectivity and resilience.

Open the BloodLink Application

Visit BloodLink Live Application

This project uses Python, Streamlit, Pandas, NetworkX and Plotly.

Note: The application explores directory data and geographical connectivity. It does not provide live blood stock information.
