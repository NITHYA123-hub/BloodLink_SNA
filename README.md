# 🩸 BloodLink – Healthcare Network Analytics

### Social Network Analysis of Blood Bank Connectivity

BloodLink is a Python-based application that uses Social Network Analysis to explore the geographical distribution and connectivity of blood banks across India.

## 🌐 Live Application

[🚀 Open BloodLink – Healthcare Network Analytics](https://bloodlink-network.streamlit.app/)

## Features
- Blood bank search and filtering
- Interactive healthcare dashboard
- Network connectivity analysis
- Network resilience simulation
- Interactive geographical network map
- Nearest blood bank finder
- Hospital blood bank search and request preparation

## Technologies Used
Python | Streamlit | Pandas | NumPy | NetworkX | Plotly

## Dataset & Network Statistics

| Parameter | Count |
|---|---:|
| Directory Records | 2,823 |
| States/UTs | 35 |
| Districts | 600 |
| Network Nodes | 2,439 |
| Network Edges | 10,248 |

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Limitations
The application uses directory-based data. It does not provide live blood stock information or automatically transmit hospital requests. Network connections represent geographical proximity only.
